The frontend sends vectors to the existing API. IVF-Flat performs centroid selection, probes the configured clusters, computes exact cosine similarity on candidates, and returns the ranked results. The benchmark's brute-force implementation remains the correctness oracle; this UI does not fake or reproduce benchmark measurements.

Semantic search: the repository's scripts/semantic_search_demo.py uses all-MiniLM-L6-v2 to turn text into real 384-dimensional embeddings. The current API frontend intentionally accepts vectors because the existing FastAPI contract exposes vector insert/search operations.

Start the backend from the repository root, then serve this folder with a local HTTP server.
